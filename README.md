# КОНСУЛТ — фирмен сайт

Персонален фирмен сайт на консултантска фирма в сферата на решаването на проблеми.

## Съдържание

- **`index.html`** — целият сайт в един самостоятелен файл (HTML + CSS + JavaScript), без външни зависимости.

## Секции на сайта

- **Начало (Hero)** — послание и призив за действие
- **За нас** — представяне на фирмата и какво гарантираме на клиентите
- **Услуги** — правни консултации, решаване на проблеми, мрежа от специалисти и др.
- **Как работим** — процес в четири стъпки
- **Защо ние** — предимства
- **Контакт** — данни за връзка и форма за запитване (отваря имейл клиента)

## Стартиране

Отворете `index.html` директно в браузър — не е необходим сървър или инсталация.

За публикуване е достатъчен всеки статичен хостинг (GitHub Pages, Netlify и др.).

## Персонализация

- **Име на фирмата** — сменете „КОНСУЛТ" в `index.html` (лого, заглавие, футър).
- **Телефон и адрес** — в секция „Контакт" (в момента са примерни placeholder стойности).
- **Имейл** — потърсете `vstrenev@gmail.com` и заменете, ако е нужно.
- **Цветове** — в CSS променливите в началото на файла (`--navy`, `--gold` и др.).
