# Жук Терапия — платежен бекенд (Cloudflare Worker)

Малък бекенд, който потвърждава SumUp плащания и праща потвърждение до клиента.
Строи се на стъпки; всяка се тества на живо, преди да минем към следващата.

## ⚠️ Сигурност
Тайният SumUp ключ (`sup_sk_…`) **никога не влиза в този репозитори**. Той се
добавя в Cloudflare като шифрован **Secret** с име `SUMUP_SECRET_KEY`.

## Деплой (изцяло през браузъра, без инсталиране)
1. Направете безплатен акаунт на **cloudflare.com**.
2. **Workers & Pages → Create → Create Worker** → дайте име (напр. `zhuk-pay`) → **Deploy**.
3. **Edit code** → изтрийте примера, поставете съдържанието на `worker.js` → **Deploy**.
4. **Settings → Variables and Secrets → Add** → тип **Secret**, име `SUMUP_SECRET_KEY`,
   стойност = вашият SumUp таен ключ → **Deploy**.
5. Отворете `https://<име>.<поддомейн>.workers.dev/me` — трябва да върне профила ви.

## Маршрути (текущо — Стъпка 1)
- `GET /health` — проверка, че бекендът работи.
- `GET /me` — валидира ключа и връща SumUp профила (merchant_code, валута).

## Следващи стъпки
2. `POST /order` — създава SumUp checkout с номера на поръчката.
3. `POST /webhook` — SumUp известява при плащане → потвърждаваме „платено".
4. Имейл до клиента „Плащането е потвърдено" + известие до собственика.
